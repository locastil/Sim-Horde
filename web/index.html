Simulating the whole world on spare graphics cards.

Sim Horde is a model of how people treat each other, too big for one computer, so volunteers run it on their own GPUs. Stage one is California: every run is scored against real county data on stress, loneliness, assaults and people moving away. Once it matches, it scales out to the rest of the planet.

What your GPU would run

The model gives each simulated person a home county, a commute, a job, friends and a mood. Day by day they meet each other, and some of those meetings go badly. The question each job answers is simple: with this particular set of behavior weights, does the simulated state look like the real one?

A job is a list of numbers, not a program. The worker you download holds only the behavior model, which you can read in full. It checks every number against its published range before it starts, and nothing it receives can make it run new code. The county data, the jobs and the scoring all come from the coordinator, so the worker only does anything as part of the horde.

Lend your GPU

The worker runs on Windows or Linux with an NVIDIA card. It uses the GPU only while a job is running, and you can stop it any time.

  1. Download the worker from GitHub and unzip it anywhere.
    Download from GitHub
  2. Double-click start_worker.bat. The first start installs what it needs, which takes a few minutes. On Linux, run ./start_worker.sh.
  3. Type a name for the leaderboard. Jobs arrive on their own from then on. Close the window to stop.

The road to the whole world

  1. California Now
    58 counties with public data to check against. This is where the model proves it can match reality.
  2. The United States
    About 3,100 counties, each with its own census, health and crime data.
  3. Every region on Earth
    Far more people than any single computer can hold, split across every GPU that joins.

Each stage starts when the one before it matches the real data. The more GPUs join, the sooner that happens.

Sim Horde is the volunteer computing arm of the California civility simulation. Public data: CDC PLACES, California DOJ, IRS migration, Census.
