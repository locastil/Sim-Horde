One shared world, powered by everyone's devices.

Sim Horde is one shared world: billions of simulated people living their days in every country on Earth, each country running on its own real statistics. It's too big for one computer, so volunteers power pieces of it from their phones, tablets and computers, and the world moves forward a month each time every piece comes back.

          What your device helps build

          Each simulated person has a home, a job or not, friends, and the ups and downs of daily life. A world job runs a few countries for one month: the people in them go about their days under that month's conditions, from the economy to protests or war. A tuning job runs a test version of California and checks it against real county data, so the model the world runs on keeps getting closer to reality.

          A job is a list of numbers, not a program. The Sim Horde app holds only the behavior model, which you can read in full. It checks every number against its published range before it starts, and nothing it receives can make it run new code. The data, the jobs and the scoring all come from the coordinator, so it only does anything as part of the horde.

          Power more of the world from a desktop

          For a desktop with a graphics card: it runs bigger pieces of the world much faster, plus the California tuning runs, and keeps going in the background. Windows or Linux with an NVIDIA card. You can stop it any time.

          1. Download the Sim Horde app from GitHub and unzip it anywhere.
            Download from GitHub
          2. Double-click start_sim_horde.bat. The first start sets itself up in a few minutes. If Python is missing, it offers to install it: press Y. On Linux, run ./start_sim_horde.sh.
          3. Type a name for the leaderboard. Jobs arrive on their own from then on. Close the window to stop.

          How happiness is measured

          Happiness is each simulated person's rating of their own life from 0 to 10, the same question real life-satisfaction surveys ask. It rises with income, work and connection to other people, and falls with stress, hardship, unrest and war.

          Once a year of simulated time, the simulation is lined up against real survey results country by country, and how closely they agree is shown above the headlines.

          Public data: World Bank Open Data; World Happiness Report survey results via Our World in Data; for California tuning, CDC PLACES, California DOJ, IRS migration and the Census.
